# Full-Stack E-commerce Website 🛒

## 📌 Project Overview

A full-stack e-commerce web application that allows users to browse products, view product details, and manage their shopping cart. The application includes a responsive frontend interface and a backend API connected with MongoDB for storing product information.

---

## ✨ Features

- 🛍️ Display products with images, descriptions, prices, and stock details
- 🔎 View individual product details
- 🛒 Add and remove products from cart
- 📦 Manage product information through backend APIs
- 💾 Store product data using MongoDB
- 🔗 Frontend and backend integration using REST APIs
- 📱 Responsive user interface
